PracticalAISMB Uploader and YouTube API Services

This section covers the PracticalAISMB Uploader app, operated by Hearth & Road LLC. The app is an internal tool. Only Hearth & Road LLC uses it, to upload its own videos to its own YouTube channel, @practicalaismb.

YouTube API Services

The app uses YouTube API Services. By using the app, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the app accesses

The app asks for one permission only: the youtube.upload scope. This lets it upload videos to the channel owner's own YouTube channel. It does not read, edit or delete any other content. It does not access other users' accounts or data.

What the app stores

  • One OAuth refresh token for the channel owner's own account.
  • The app's OAuth client credentials (client ID and client secret).

The authorization token is stored as an access-restricted secret in our private automation environment. It is never placed in code, on this website, or in shared files, and it is used only to upload videos to our own channel.

The app stores a token only for Hearth & Road's own channel. It stores no tokens from any other user, and no other user data. It uses no cookies and no analytics.

How the data is used and shared

We do not sell or rent this data. The token is used only to send our own uploads to Google (YouTube), and we do not share it with anyone else. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How to revoke access

You can revoke the app's access at any time on the Google security settings page at https://security.google.com/settings/security/permissions. Revoking stops the token from working right away.

When access is revoked, or on request to PracticalAISMB@hearthandroad.com, we delete the stored token as soon as possible and within 30 days.
